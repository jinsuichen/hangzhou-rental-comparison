# 杭州租房对比

按小区比较通勤，按小区聚合具体房源的静态网站。当前快照采集于 2026-11-03 至 2026-11-04，收录 60 个小区、95 条房源记录，其中 81 条为官网新增。2026-11-04 分三批扩展了 51 个小区，每个新增小区均核对 1 套官网房源及实景图，并通过高德 MCP 查询两个目的地的四种通勤方式。

支持搜索、筛选、实景图放大，以及保存在访问者浏览器中的房源排除标记。排除状态不会同步给其他人。列表采用整页滚动。房源页统一使用紧凑的小区下拉选择器，内容占满页面宽度。手机端以卡片展示通勤与房源，支持折叠筛选条件及图片放大。两个目的地均可按打车、地铁、骑行、步行的耗时排序，支持正反排序，不详和不推荐的路线始终排在末尾。

两个页面共享租金区间、面积区间、户型，以及到两处目的地的出行方式和最长耗时筛选。条件同时生效并随页面切换保留；小区仅在有符合全部条件的房源时展示。启用限时后，不详或不推荐的路线不匹配。面积使用页面主展示面积。

## 项目结构

- `src/index.html`：页面骨架
- `src/styles.css`：样式
- `src/app.js`：筛选、聚合和交互
- `src/commute-sort.js`：通勤耗时排序及未知值处理
- `public/data/listings.json`：房源和小区通勤快照
- `public/images/`：页面使用的图片
- `scripts/build.mjs`：校验数据和资源并生成 `dist/`
- `vercel.json`：Vercel 构建配置

## 构建与部署

使用 Node.js 22 或更新版本，无第三方运行依赖：

```sh
npm run check
```

在 Vercel 导入本仓库，构建命令为 `npm run build`，输出目录为 `dist`。提交到生产分支后由 Vercel 自动部署。

## 更新数据

编辑 `public/data/listings.json`，保留房源编号的稳定性。新图片放入 `public/images/`，在房源的 `image` 与 `实景图` 字段填写对应的 `/images/...` 路径，再运行构建检查。

每条记录必须填写 `来源链接`（完整前端 HTTPS URL）和 `来源链接类型`（`房源详情` 或 `小区搜索`），不能仅保存房源编号。原房源地址未保存的早期记录使用对应小区搜索链接，并明确标记原房源链接不详。构建会校验链接格式及搜索小区是否一致。内部编号仍用于稳定匹配和排除标记。

## 信息边界

房源条件来自采集时的页面展示，未披露字段统一为“不详”。页面可打开不代表当前仍可租；部分截图中的图片加载不完整，实拍真实性未核验。通勤仅来自高德 MCP，以小区 POI 为起点；打车使用驾车路线参考，不含候车时间。目的地为爱力中心与阿里西溪 A 区3号门。

原始群聊截图、完整浏览记录和本机路径不包含在公开项目中。图片和房源内容的相关权利归原权利人所有。
